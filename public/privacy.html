DPE Énergie

Confidentialité

Le moins de données possible.

Cette notice décrit le comportement de la plateforme publique actuelle. Elle ne remplace pas les politiques propres aux services externes consultés.

Ce que la plateforme ne fait pas

  • aucun compte utilisateur ;
  • aucune base de profils Muze-X Lab ;
  • aucune publicité ni SDK publicitaire ;
  • aucun outil d’analytics ou de profilage comportemental ajouté par l’application ;
  • aucune collecte de PRM/PDL dans le module Énergie ;
  • aucun secret ou credential demandé dans le navigateur.

Module DPE

Recherche ADEME

Le numéro de DPE saisi est utilisé par le navigateur pour interroger directement les jeux de données publics ADEME. La plateforme n’ajoute pas de serveur applicatif intermédiaire et ne conserve pas ce numéro dans une base Muze-X Lab.

L’adresse complète éventuellement renvoyée par la source publique n’est pas affichée par défaut. Une localisation réduite est privilégiée dans le résumé.

Module Énergie

Calcul local

Les valeurs saisies — consommation annuelle, puissance souscrite et prix éventuels — sont utilisées uniquement dans le navigateur pour produire l’affichage demandé. Cette version ne transmet pas ces valeurs à un serveur Muze-X Lab.

Infrastructure et services externes

GitHub Pages héberge les fichiers publics de la plateforme. Comme tout service web, l’hébergeur peut traiter les données techniques nécessaires à la connexion, notamment l’adresse IP, selon ses propres conditions.

Lorsque le module DPE interroge l’ADEME ou lorsque l’utilisateur ouvre un lien externe, le service concerné reçoit les données techniques nécessaires à cette connexion selon sa propre politique.

Principe actuel

Pas de compte par défaut, pas de profilage, pas de conservation applicative des valeurs saisies et traitement local dès que la fonction le permet.
